# CPV Player

## Tools

All tools are in the `tools` subdirectory.

### `convert.py` Convert a video file to a cpv file.

**Syntax:** `python3 convert.py <video file> --output <cpv file> --width <width> --height <height> --fps <fps>`

**Note:** the video file must be ffmpeg compatible.

### `play.py` Play a cpv file to test on the host.

**Syntax:** `python3 play.py <cpv file>`
